# LLaVA-GM: Lightweight LLaVA Multimodal Architecture

This repository is a landing page for the **LLaVA-GM** research paper. It currently contains no implementation code, checkpoints, or model weights, so the model cannot be run from this repository.

## Research overview

The paper explores a more lightweight LLaVA-style vision-language architecture for visual question answering (VQA). It replaces the language backbone with Gemma, introduces mixture-of-experts (MoE) layers to reduce active computation, and uses a staged training strategy.

## Paper

**LLaVA-GM: lightweight LLaVA multimodal architecture**  
Published in *Frontiers in Computer Science*, September 2025.

[Read the full paper](https://www.frontiersin.org/journals/computer-science/articles/10.3389/fcomp.2025.1626346/full) · [DOI: 10.3389/fcomp.2025.1626346](https://doi.org/10.3389/fcomp.2025.1626346)

## Reproducibility

The paper describes the architecture and experiments, but this repository does not currently provide code or weights to reproduce them.
