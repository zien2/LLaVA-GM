# LLaVA-GM: Lightweight LLaVA Multimodal Architecture

> **This is an independent paper overview, not the official LLaVA-GM implementation.** The paper does not provide a GitHub code link, and this repository contains no implementation code, checkpoints, or model weights. You cannot run or reproduce the model from this repository.

## Research overview

The paper explores a lightweight LLaVA-style vision-language architecture for visual question answering (VQA). It replaces the language backbone with Gemma, introduces mixture-of-experts (MoE) layers to reduce active computation, and uses a staged training strategy.

## Paper

**LLaVA-GM: lightweight LLaVA multimodal architecture**  
Published in *Frontiers in Computer Science*, September 2025.
